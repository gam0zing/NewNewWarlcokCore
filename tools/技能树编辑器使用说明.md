# 技能树编辑器 · 使用说明

这个网页就是个"画图工具"：把命令拖到画布上变成节点，用线连起来，最后导出一个 JSON 文件丢进数据包，游戏里的技能树就是它了。不用写代码。

---

## 一、打开前先备好一份"命令清单"

编辑器得先知道游戏里有哪些命令能用。

1. 启动一次游戏（或测试服务端）。
2. 模组会自己生成一个文件，在游戏目录下：
   `newnew_warlock_core/command_definitions.json`
3. 打开网页，点右上角「导入命令定义」，选这个文件。
4. 左边「命令库」出现一排卡片，就成了。

> 小提示：页面自带物品、属性、药水效果的预设（`builtin_enums.js`），填参数时会有带图标的搜索下拉，不用另外准备。想加自己的预设，再点「导入 enum 表」。

---

## 二、界面就三块

- **左边**：树的设置 + 命令库（上面能搜索）
- **中间**：画布，干活的地方
- **右边**：选中节点后，在这儿改它的名字、图标、参数

---

## 三、五步做出一棵树

1. **建节点**：从左边把命令卡片拖到画布上。也可以点一下卡片按回车，或双击卡片，节点会出现在画布中间。
2. **改样子**：点节点，右边就能改名称、描述、图标物品。图标留空就显示一个空槽。
3. **连前置**：点节点会弹出小菜单，选「建立连接」，再点另一个节点就连上了。方向是"前置 → 后继"，箭头从先解锁的指向后解锁的。也可以在右边「添加前置」里选。
4. **填参数**：右侧每个命令下面就是参数。字符串不能空着，数字只能填数字，开关就是勾选。有预设的字段右边有个小箭头，点开能搜。
5. **导出**：点「导出技能树」（或按 Ctrl+S）。有错会拦住你并列出原因；只是提醒的话，可以点「仍然导出」。

> 关于前置：一个节点有多个前置时，**任意一个**解锁了就能解锁它。没有前置的节点就是根节点，随时能点。

---

## 四、画布上怎么操作

| 想干什么 | 怎么做 |
| --- | --- |
| 移动视野 | 按住空白处拖 |
| 放大缩小 | 滚轮 |
| 移动节点 | **长按节点约 0.35 秒**再拖（直接拖是单击，会弹菜单） |
| 吸附到父节点 | 拖动时按住 **Ctrl**：按鼠标相对父节点的角度吸附到 30 度的整数倍（0/30/60/…/330 度），距离吸附到 2 个节点边长的整数倍 |
| 精确改坐标 | 选中节点后，在右侧检查器直接修改 X / Y 坐标 |
| 复制 / 粘贴节点 | 选中后 Ctrl+C / Ctrl+V（只复制节点，不复制连线） |
| 删除节点 | 点节点 → 菜单里选「删除」，或右边红按钮 |
| 取消当前操作 | Esc |

点空白处 = 取消选中。

---

## 五、左边那几个设置

- **树 ID**：格式是 `命名空间:名称`，比如 `newnew_warlock_core:skill_tree`。它决定导出的文件叫什么、该放哪儿。
- **显示名称**：游戏里页签上显示的字。
- **页签排序**：数字越小越靠前。
- **每重置 1 点消耗经验等级**：洗点价格，填 0 就是不要经验。
- **默认解锁本树**：勾上后玩家一上来就能看到这棵树。

---

## 六、导出之后放哪儿

导出的文件名是树 ID 里冒号后面那段（斜杠会变成下划线）。把它放到：

```
data/<命名空间>/skill_trees/<名称>.json
```

然后游戏里执行 `/reload`，就能看到了。

## 七、远程仓库（多人协作）

仓库是一个独立的 Node 服务（NestJS），用来存放技能树的各个版本。默认只监听 `127.0.0.1`，公网访问请用内网穿透（ngrok / frp）转发到本机端口。

### 1. 打包并一键搭建（推荐）

两个工具都在 `tools/` 下：

| 工具 | 位置 | 作用 |
| --- | --- | --- |
| 打包工具 | `tools/build-server-package.js` | 生成纯净分发包（不含 `node_modules`、`dist`、`.env`、`tree_store`） |
| 一键安装器 | `tools/server-installer/` | 随分发包一起发出，运行后自动展开并启动服务端 |

打包：

```bash
node tools/build-server-package.js                  # 产物：tools/release/NewNewSkillTreeServer-v1.0.0.zip
node tools/build-server-package.js --out D:\x.zip   # 自定义输出路径
```

把 zip 发给对方，对方解压后：

- Windows：双击 `install.bat`
- macOS / Linux：`node install.js`

安装器会依次完成：复制文件 → 生成随机令牌写入 `server/.env` → `npm install` → `npm run build` → 用 pm2 启动 → 健康检查，并打印编辑器地址与令牌。默认装到当前目录下的 `SkillTreeServer`；重复运行可原地升级，保留 `.env` 与 `tree_store`。

### 2. 手动启动服务

需要 Node.js 18+ 和 npm。

```bash
cd tools/server
npm install                 # 依赖全部通过 npm 下载
cp .env.example .env        # Windows 用 copy .env.example .env
# 编辑 .env，把 EDITOR_TOKEN 改成一段足够长的随机字符串
npm run build
npm run pm2:start           # 等价于 pm2 start ecosystem.config.js
```

- 本机打开 `http://127.0.0.1:8787/editor.html`。
- 公网访问：`ngrok http 8787`，把 ngrok 给出的 https 地址发给别人。页面和接口同源，直接打开即可。
- 常用命令：`npm run pm2:logs`、`npm run pm2:restart`、`npm run pm2:stop`。改完代码先 `npm run build` 再重启。
- 没装全局 pm2 也可以：`npx pm2 start ecosystem.config.js`。

### 3. 在编辑器里连接

顶部「仓库」→ 填写三项 → 点「保存设置」：

| 项 | 说明 |
| --- | --- |
| 作者 ID | 你的名字，会记录在版本信息里；第一次上传也会要求填写，之后缓存在本机 |
| 服务器地址 | 页面由仓库服务托管时可留空；用 `file://` 打开时默认 `http://127.0.0.1:8787` |
| 访问令牌 | 与服务端 `.env` 里的 `EDITOR_TOKEN` 一致，只保存在本机浏览器 |

保存后会自动刷新树列表。左边是树，右边是这棵树的版本检查器，底部是操作区。

### 4. 上传与拉取

- **顶部「上传」**：未关联远程时作为新树推送；已关联时作为新版本推送。远端已有更新版本会被拦住，需要先拉取。
- **推送当前工作区作为新版本**：只有工作区基于远端最新版本时才可用，按钮上会显示即将生成的版本号。
- **拉取到工作区**：弹窗里三选一——取消 / 先备份再覆盖 / 直接覆盖。
- **下载 zip**：压缩包内含 `tree.json` 与 `meta.json`。

推送前会输入一条版本说明（可留空）。作者 ID 为空时会先要求填写并缓存。

### 5. 数据放在哪

每个版本一个目录：

```
tools/tree_store/{树名称}_v{4位版本号}_{上传者}/
  tree.json
  meta.json
```

- `tree.json` 就是游戏用的技能树，根级多了一个 `meta`（原作者、版本、编辑者、编辑时间、版本说明）。游戏解析器会忽略未知字段，不影响加载。
- `meta.json` 额外记录 `tree_id`、`uploader`、`uploaded_at`、`sha256`、`game_tree_id` 等，服务端据此归组版本。
- 目录名重名时会自动追加短哈希，已存在的版本目录不会被覆盖。

### 5. 安全与限制

- 默认只监听 `127.0.0.1`；公网请求必须是 HTTPS（ngrok 自带），否则拒绝。
- 除 `/api/health` 外，所有接口都要 `Authorization: Bearer <令牌>`。
- 单次上传上限 5MB；同一 IP 每分钟最多 30 次写请求。
- 静态托管只开放编辑器页面、内置 enum、命令定义和 `tree_store` 只读文件，`server/`、点文件、`node_modules` 不可访问。
- 上传（新建树 / 新版本）会记录到 `tools/server/audit.log`。

## 八、常见问题

- **左边命令库是空的？** 还没导入命令定义，见第一步。
- **关掉网页东西会没吗？** 不会，草稿自动存在浏览器里，下次打开还在。点「新建」才会清空（会先问你）。
- **参数填错了会怎样？** 导出时会报错并指出是哪个节点、哪个参数，照着改就行。
- **双击 html 打开后，命令清单没自动加载？** 浏览器出于安全会拦截本地文件读取，手动点「导入命令定义」就行；或者用本地 http 服务打开。
- **节点没有命令会怎样？** 解锁不消耗点数，也不产生效果——通常用来做纯路过的节点。
